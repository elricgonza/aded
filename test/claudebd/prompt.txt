8e desea contar con un sistema de gestión escolar que permita administrar la información de estudiantes, profesores, cursos, inscripciones, pagos y otros aspectos relacionados con la gestión educativa, como el seguimiento de la asistencia, el rendimiento académico, la asignación de materias a profesores, entre otros. Para este propósito se solicita una propuesta del diseño de la base de datos (en Postgres) con la estructura de tablas, respectivas llaves primarias, llaves foráneas, relaciones, etc. y procesos para la gestión escolar, considerando además usuarios, roles y permisos para el acceso, retornar el script correspondiente para la creación de la propuesta de la base de datos, además del diagrama entidad relación.
