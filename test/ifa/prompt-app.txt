Escribir todo el código necesario para ejecutar el software de gestión para un Instituto de Educación Musical (IFALFA), especificando las instrucciones para la instalación, configuración y ejecución del software, 

Proyecto: Software de gestión para un Instituto

Software a utilizar:
===================
-Base de datos: Postgres
-Backend: Python, Flask
-Frontend: HTMX, Alpine.js, Tailwind CSS
(complementar y utilizar otro software si es necesario y justificado)

Características:
===============
-Debe ser responsivo
-Debe contar con la autenticación y autorización de usuarios

Requerimientos funcionales:
==========================
-Existirán los siguientes roles: Administrador, Profesor, Estudiante, Consulta, transcriptor
-Los permisos serán asignados según el rol asignado a cada usuario


Resumen descripción de tablas:
=============================
-gestion: (gestión académica): para cada gestión se registra el año
-instrumento: se registra el nombre de los instrumentos que se imparten en el instituto
-grado: (grado educativo) se registra el nivel y el grado correspondiente a una gestión (referencia a tabla gestion)
-materia:  se registra el nombre de las materias que corresponde a un determinado grado (referencia a tabla grado)
-requisito: se registra la materia y las materias que son requisito para cursarla (referencia a tabla materia)
-profesor: se registra el nombre del profesor que imparte una o varias materias (referencia a tabla asignado)
-curso: se registra el nombre del curso que corresponde a un determinado grado (referencia a tabla grado)
-asignado:  se registra la asignación de un profesor a una materia, un alumno y un curso (referencia a tabla profesor, materia, inscrito  y curso)
 --se considerán las materias que corresponden a un determinado grado por defecto
 --también es posible asignar materias de otros grados (cuando en inscrito el campo "otras_materias" es verdadero)
-alumno:  que deben inscribirse en un curso (referencia a tabla curso)
-inscrito: se registra la inscripción de un estudiante a un curso (referencia a tabla alumno y curso) 
-nota: se registra la nota obtenida por un estudiante en una materia (referencia a tabla inscrito a través de la cual se obtiene el curso, la asignación de profesor y materia)
-pago:  se registra pagos 
 --esta tabla es generada a partir de la inscripción generando un registro de pago, aplicando el descuento (especificado en el campo descuento que corresponde al porcentaje de descuento si corresponde)
 --esta tabla se actualiza cuando el estudiante realiza un pago, registrando la fecha del pago, el monto pagado

Tablas de administración de usuarios, roles y permisos:
======================================================
-usuario: (Usuarios) Administración de usuarios
-rol:  administra los roles asignados a usuario
-permiso: administra los permisos 
-usuario_rol:  (usuario_rol) roles asignados a un determinado usuario
-rol_permiso:  permisos asignados a un determinado rol
