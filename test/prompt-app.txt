Escribir todo el código necesario para ejecutar el software de gestión para una unidad educativa, especificando las instrucciones para la instalación, configuración y ejecución del software, 

Proyecto: Software de gestión para una unidad educativa

Software a utilizar:
===================
-Base de datos: Postgres
-Backend: Python, Flask
-Frontend: HTMX, Alpine.js, Tailwind CSS
(complementar y utilizar otro software si es necesario y justificado)

Características:
===============
-Debe ser responsivo
-Debe contar con la autenticación y autorización de usuarios

Requerimientos funcionales:
==========================
-Existirán los siguientes roles: Administrador, Profesor, Estudiante, Consulta, transcriptor
-Los permisos serán asignados según el rol asignado a cada usuario


Resumen descripción de tablas:
=============================
-gestion: (gestión académica): para cada gestión se registra el año
-grado: (grado educativo) se registra el nivel y el grado correspondiente a una gestión (referencia a tabla gestion)
-materia:  se registra el nombre de las materias que corresponde a un determinado grado (referencia a tabla grado)
-profesor: se registra el nombre del profesor que imparte una o varias materias (referencia a tabla asignacion)
-curso: se registra el nombre del curso que corresponde a un determinado grado (referencia a tabla grado)
-asignacion:  se registra la asignación de un profesor a una materia y a un curso (referencia a tabla profesor, materia y curso)
 --se considerán las materias que corresponden a un determinado grado.
-estudiante:  que deben inscribirse en un curso (referencia a tabla curso)
-inscrito: se registra la inscripción de un estudiante a un curso (referencia a tabla estudiante y curso) 
-calificación: se registra la calificación obtenida por un estudiante en una materia (referencia a tabla inscrito a través de la cual se obtiene el curso, la asignación de profesor y materia)
-costo: se registra el costo de cada curso el número de cuotas que se debe pagar y el monto de la cuota (referencia a tabla curso)
-pago:  se registra el plan de pagos con todas las cuotas que debe pagar el estudiante , referencia a tabla inscrito a través de la cual se obtiene datos del estudiante y del curso ) 
 --esta tabla es generada a partir de las tablas: inscrito, curso y costo; por cada estudiante inscrito en un curso se genera un plan de pagos con el número de cuotas y el monto de cada cuota, aplicando el descuento (especificado en el campo descu que corresponde al porcentaje de descuento a aplicar de la cuota por curso) si corresponde 
 --esta tabla se actualiza cada vez que el estudiante realiza un pago, registrando la fecha del pago, el monto pagado y el número de cuota que se está pagando

Tablas de administración de usuarios, roles y permisos:
======================================================
-usr: (Usuarios) Administración de usuarios
-rol:  administra los roles asignados a usuario
-permiso: administra los permisos 
-usr_rol:  (usuario_rol) roles asignados a un determinado usuario
-rol_permiso:  permisos asignados a un determinado rol
